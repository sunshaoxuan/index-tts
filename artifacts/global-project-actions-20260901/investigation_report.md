# 工程级生成操作跨工作区修复报告

## 问题

“生成完整音频”在分句导演等工作区显示为禁用，当前工程有 154 条分句且后台没有活动任务。

## 根因

`projectActionAvailability` 把 `activeTab === 'delivery'` 作为完整音频生成的必要条件。AI 全文分析和角色音色生成也采用相同的页签门控。项目操作面板属于全局浮动操作入口，这种门控使工程级操作在多数工作区看起来失效。

## 修复

1. 三个工程级生成操作只依据真实数据前置条件和后台任务互斥状态启用。
2. 操作提交成功后自动进入对应结果工作区。
3. 数据缺失或任务运行时提供明确的禁用原因。
4. 需求文档第 103 条和 CHANGELOG 已同步更新。

## 运行验收

独立镜像 `indextts25-product-studio:1.1.60-global-actions-working` 使用“白夜行03”轻量工程副本在 7865 验收。全文与体裁、角色资产、分句导演、完整音频与交付四个工作区内，AI 全文分析、角色音色生成和完整音频生成均为启用状态。Console 日志为空，浏览器截图检查通过。验收未点击生成按钮，以免启动 154 条实际音频渲染。
