# 最终验收清单

验收基准为用户最初报告：高级三版必须都保持角色参考音色，后两版不能因生成策略绕过参考音色约束，同时页面必须展示并播放真正的新三版。

| 初衷级要求 | 可检查成果物 | 验收方法 | 状态 |
|---|---|---|---|
| 三版使用同一角色参考 WAV | 推理调用和单元测试 | 断言每次 `spk_audio_prompt` 等于同一路径 | 合格 |
| 三版差异不随机替换情绪原型 | `text_director.py` | 断言高级三版每次 `use_random=False` | 合格 |
| 明显音色漂移不能进入三选一 | 0.82 CAMPPlus 门禁 | 真实新三版均高于 0.82 | 合格 |
| 候选必须通过完整自动门禁 | `quality_passed` 筛选 | 三版音质、音色和完整门禁均通过 | 合格 |
| 候选不足时保护原片断 | 异常保护与回归测试 | 九次不足三版时抛出明确错误且原片断保持 | 合格 |
| 新三版等待人工试听 | 最新渲染数据和页面 | 三版均未采用，提供“采用此版” | 合格 |
| 页面展示最新候选集合 | 服务端协调排序和回归测试 | 同序号旧已采用与新待选共存时选择后写入记录 | 合格 |
| 页面显示正确分数和门槛 | 第 24 句真实页面 | 0.863、0.863、0.845，门槛 0.820 | 合格 |
| 三个候选音频实际可播放 | 浏览器媒体状态和 HTTP | `readyState=4`，播放时间推进，HTTP 200 | 合格 |
| UI 无运行错误并有截图 | Console 与 PNG | error 0 条，截图可见三张候选卡 | 合格 |
| 运行服务应用当前代码 | Docker 与健康接口 | 镜像、OCI revision、healthy、RestartCount 0、HTTP 200 | 合格 |
| 自动测试与构建 | 测试记录 | 聚焦、完整回归和生产构建通过 | 合格 |
| 需求变更有文档记录 | CHANGELOG 与需求架构文档 | 检查本次修复合同已写入 | 合格 |
| 代码进入 Git master | 两次功能提交和最终证据提交 | HEAD、本地跟踪分支与远端 master 三方等值 | 合格 |

任何一项失败时，修复后从本清单第一项重新执行。
