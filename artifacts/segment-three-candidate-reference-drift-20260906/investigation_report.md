# 分句三版参考音色漂移调查报告

## 用户现象

分句使用高级三版生成时，第一版接近角色参考音色，后两版明显跑偏，导致三选一失去实际价值。

## 根因

1. 三次推理都传入了同一个角色参考 WAV，参考音频参数没有缺失。
2. 高级三版原先启用 `use_random=True`。该选项会随机选择情绪嵌入原型，变化会侵入说话人身份。
3. 原 CAMPPlus 音色相似度门槛为 0.72。真实旧候选 0.838211、0.772144 和 0.739627 全部被放行，门槛无法阻止后两版明显漂移。
4. 最终候选筛选原先只硬性检查基础音质，没有把音色和适用重音校验纳入完整硬门禁。
5. 首次修复部署后发现展示层仍会在同序号旧已采用记录和新待选记录之间优先选择旧记录，页面因此显示旧三版和旧门槛。

## 修复合同

1. 每次候选推理固定使用角色当前同一个参考 WAV。
2. 分句高级生成固定 `use_random=False`，候选差异由模型采样产生。
3. CAMPPlus 音色相似度门槛提高到 0.82。
4. 候选必须同时通过音质、音色和适用重音门禁后才能进入三选一。
5. 最多九次仍不足三版时终止本轮更新，保留原片断并报告失败。
6. 同一分句存在旧已采用记录和新待选三版时，页面优先展示后写入的新候选集合。
7. 新三版保持未采用状态，最终效果由使用者试听选择。

## 结论

这次问题由随机情绪原型、较低音色门槛、不完整候选筛选和旧记录展示优先级共同造成。当前生成层、门禁层和展示层均已修复。真实第 24 句的新三版相似度集中在 0.845174 至 0.862589，全部高于 0.82，页面保留人工试听采用流程。
