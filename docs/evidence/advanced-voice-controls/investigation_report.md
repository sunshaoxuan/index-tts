# 角色高级声音控制调查报告

## 目标

让每个角色独立调整可感知声音特征和 Qwen VoiceDesign 原生生成参数，并验证年龄设定能够形成方向明确的声音差异。

## 实现结论

角色资产现在包含十二项零到一百语义声音特征、地域或口音、角色专属试听文本、生成策略、主采样参数、Subtalker 采样参数、随机种子、最大生成 Tokens 和一至六个候选。语义特征会转换为明确的 VoiceDesign 自然语言指令，原生参数会直接传给 `generate_voice_design`。

每个候选独立保存 WAV、种子、中位基频、目标差值和年龄及性别门禁结果。系统先筛选有效候选，再选择最接近目标的候选。全部候选会注册进永久音色库，用户可以试听并采用任一候选。

`voice_generation` 已进入声音签名。修改一个角色的声音特征或生成参数只会让该角色的稳定音色失效。头像和候选选择不会让其他角色音色失效。

## 年龄验证

真实模型使用同一段中文试听文本生成十岁、三十五岁和七十二岁男性声音。最佳候选指标如下。

| 年龄 | 中位基频 | 频谱重心 | 时长 | 频谱平坦度 |
| ---: | ---: | ---: | ---: | ---: |
| 10 | 269.73 Hz | 3366.34 Hz | 6.00 秒 | 0.05191 |
| 35 | 114.18 Hz | 2841.90 Hz | 6.64 秒 | 0.04695 |
| 72 | 94.60 Hz | 3200.37 Hz | 7.60 秒 | 0.11772 |

儿童基频显著高于成年人，成年人基频高于老年人。老年声音时长更长，频谱平坦度更高，符合更慢、纹理更明显的目标方向。自动检查四项全部通过。

第一轮儿童样本出现约 103.7 Hz 的成年低音。修正后，儿童门禁按未变声阶段使用更宽容的年龄区间，提示明确要求尚未变声的儿童声线，并排除成年男性低音和厚重胸腔共鸣。重新生成的最佳儿童候选达到 269.73 Hz。

## 能力边界

中位基频、频谱、时长和纹理指标能够验证年龄差异方向。最终感知年龄仍与文本、语言、模型随机性和听者判断有关，正式作品建议在候选列表中试听后选择。
