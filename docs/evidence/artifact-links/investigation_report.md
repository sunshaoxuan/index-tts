# 成果物链接调查与实现

## 用户初衷

完整交付完成后，用户需要在交付页直接找到成果物。下载操作与可定位链接必须同时存在。

## 已确认缺口

原页面只为分轨包和导演清单显示下载按钮，完整音频只有播放器；完整音频、分轨包和导演清单的 URL 均未作为可见链接显示。

## 实现

交付区新增完整音频下载按钮。三个成果物分别显示下载按钮、打开链接、绝对 URL 和复制按钮。URL 来自现有 `latest-render` 文件 API，并以当前页面 origin 转为绝对地址。

## 运行态发现

生产构建产生新静态资源指纹后，旧 Node 进程尚未登记新文件，首次刷新把新 JS 路径回退为 HTML。重启 7864 服务后，新 JS 以 `application/javascript` 返回，页面恢复并完成验收。
