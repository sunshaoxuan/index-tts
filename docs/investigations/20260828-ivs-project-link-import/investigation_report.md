# IVS 项目关联与角色音色导入调查及实现报告

## 需求

新建声音工程时可关联一个或多个已有工程，并导入来源工程的角色以及每个角色的全部音色。

## 已验证实现

1. 新建工程窗口提供多选来源工程，选项显示来源工程角色数。
2. 创建接口接收 `source_project_ids`，导入角色表、结构化角色资产、当前音色和全部候选音色。
3. 多来源工程出现相同角色 ID 时，为新工程分配不冲突的稳定目标 ID。
4. 新工程保存 `linked_projects` 回执，记录来源工程、角色 ID 映射、可用音色和缺失音色。
5. 导入是创建时快照，创建完成后各工程独立维护。
6. 仅规范化来源快照中的角色投影，避免处理大型导演历史。

## 运行证据

真实来源工程 `20260825-104455-白夜行01-869866` 的 `project.json` 为 16,094,240 字节，包含 8 个角色。返工后创建关联工程耗时 116 ms，导入 8 个角色和 22 个音色引用；22 个音色文件全部可用，缺失数为 0。

内置浏览器显示新建窗口包含“关联已有工程并导入角色音色”多选项，来源选项显示 8 个角色。创建后工作区显示“角色资产 8”，Console 错误和警告列表为空。

截图调用在普通视口和限定 1280 × 900 视口连续两次超时，未生成有效截图文件。截图验收状态为 `evidence_missing`。

## 限制

关联记录用于审计导入来源，不提供来源工程后续变更的自动同步。来源项目内已经缺失的音色文件会保留候选 ID，并写入 `missing_voice_ids`。
