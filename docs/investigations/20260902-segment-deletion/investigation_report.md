# 分句删除功能调查与实现报告

## 目标

在分句导演中删除无需朗读的注释类分句，保留完整正文原稿，并保证后续分句编号、缓存复用、完整交付状态和工程保存行为一致。

## 行为链

1. React 表格以稳定分句序号保存跨页选择。
2. `deleteSegmentsByOrder` 校验所选序号、移除目标记录并连续重排剩余分句。
3. 页面清除临时选择和拆分状态，登记工程未保存状态。
4. 工程 PUT 保存后，服务端以不含序号的完整分句身份比较新旧记录。
5. 被删除记录的过程缓存被移除，包含该记录的完整交付被标记过期。
6. 原文、合成文字、角色、语言和导演参数未变化的后续片断继续匹配，并迁移到当前序号。

## 失败与修正

- 首次建立测试分句时，新建工程没有默认角色，服务端以“分句 1 引用了未知角色”拒绝保存。读取工程真实角色表后显式加入合法旁白角色，再建立测试数据。
- 首次浏览器复选框定位使用快照展示名称，没有匹配实际可访问名称。改为以注释原文限定表格行，再定位行内唯一复选框。
- 原稿文本域的精确占位定位在页签切换动画中超时。改为读取当前页签文本域值集合并核对注释原文。
- 正式上线后的首次完整测试复跑因当前终端 PATH 缺少 `node` 而未启动测试。临时加入 Codex Node 运行目录后，完整 170 项测试全部通过。
