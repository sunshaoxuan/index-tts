# 角色音色候选与年龄性别回归调查

## 用户观察

1. 当前版本生成角色音色后直接确定当前音色，没有出现原有的三选一。
2. 松浦勇显示为女声。
3. 十岁男孩桐原亮显示为成年男子声线。

## 已验证根因

1. 全文分析先把工程音色和全局永久音色库组合为一个无角色属性的 ID 列表，再由 `document_to_tables` 按弱名称偏好和顺序给 AI 新角色分配声音。松浦勇实际取得原角色“死者妻子”的 `voice-6d7e04bb41b6b289`，桐原亮实际取得 55 岁旁白的 `voice-c4bf3e1793350e26`。
2. VoiceDesign 已按角色配置生成三个候选，worker 同时把最接近目标频率的候选标记为 `selected=true`，Product worker 随即改写角色当前稳定音色。候选入口只存在于角色编辑弹窗，用户无法在生成结束后看到集中三选一。
3. 桐原亮的旧指令同时要求“十岁男性自然发声、男性声带质感和男性共鸣”与“尚未变声儿童声线”。前一组措辞会诱导成年男性低音。真实九次结果为 93.98 至 106.35 Hz，全部属于当前儿童门禁拒绝范围。
4. VoiceDesign 对任一角色候选不足时抛出异常，导致同批次前面角色已经合格的候选没有进入永久音色库和工程候选资产。
5. 修复后首次真实重试中，松浦勇成功得到 116.99、103.73、111.11 Hz 三个男性候选。桐原亮的长指令仍在 9 次中产生 91.31 至 139.28 Hz，其中 139.28 Hz 被原有儿童宽门禁判为合格，暴露门禁未严格使用角色资产 190 至 320 Hz 区间。
6. 同一驻留模型改用简洁正向男童指令后，三次直接得到 238.12、293.45、269.29 Hz，全部落在 190 至 320 Hz 角色资产区间。这证明长人物小传、旧“低沉”导演和成人化节奏会稀释童声身份。

## 修复合同

1. AI 新增角色保持当前音色为空并标记需要生成，匹配已有角色继续复用原稳定角色 ID 和资产。
2. 默认生成三个通过年龄与性别门禁的候选，全部以 `selected=false` 登记。用户在集中候选区试听并采用后才改写角色当前稳定音色。
3. 十三岁以下角色使用未变声男童或女童身份措辞，移除通用男性或女性共鸣要求。默认儿童试听文本明确角色年龄和放学语境。
4. 单个角色失败写入结构化失败列表并继续处理后续角色，其他角色的完整合格候选照常登记。
5. 十三岁以下角色使用简洁正向童声模板，不把长小传、成人排除词、旧“低沉”导演或成人化节奏传给 VoiceDesign；生成后严格使用角色资产基频上下限验收。
