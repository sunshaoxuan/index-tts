# 最终验收清单

验收基准：所有可能长时间等待的操作都必须提供取消按钮，覆盖单个音频、多个或完整音频、图片和 AI 操作，使用者无需被动等待。

| 原始要求 | 可检查成果 | 验收证据 | 结果 |
|---|---|---|---|
| 单个音频可取消 | 单分句任务进入统一后台队列，进度浮层提供取消按钮 | 后台任务 API、UI 静态契约、活动 Worker 取消测试 | 合格 |
| 多个或完整音频可取消 | 完整音频、严格串接和角色音色共用统一取消路由 | 任务类型映射、活动与等待任务取消测试 | 合格 |
| 图片操作可取消 | 单张关键帧、全量关键帧和角色形象有就近取消按钮 | 桌面截图、全量 `1 / 2` 取消、上游中止记录 | 合格 |
| AI 操作可取消 | 全文分析、AI 分镜、人物扩写和两类服务测试均有取消入口 | 后台任务截图、人物扩写浏览器验收、静态契约测试 | 合格 |
| 取消真正停止对应工作 | Worker 被终止，上游请求收到 AbortSignal，批量不启动下一张 | 单元测试、模拟服务 completed 1 且第二请求 aborted | 合格 |
| 取消不会误伤其他 Runtime | Runtime 终止前核对请求 ID、processing 信封和状态路径 | Runtime 归属单元测试 | 合格 |
| 取消后不丢失已完成成果 | 批量关键帧逐张回写，取消后保留第一张 | 浏览器最终 DOM 只存在“窗边观察关键帧” | 合格 |
| 取消后界面恢复可用 | 后台工程锁、图片锁和人物表单锁均解除 | 浏览器 DOM 与状态文本 | 合格 |
| 桌面和移动端均可操作 | 桌面与 390 x 844 移动视口有可见按钮，无水平溢出 | 桌面和移动截图，overflow 0 | 合格 |
| 页面无运行异常 | 浏览器 Console 无错误和警告 | 最终干净标签页日志 | 合格 |
| 文档记录需求变化 | 正式需求、架构、README 和 CHANGELOG 已更新 | 对应文档差异 | 合格 |
| 代码质量与构建 | 单元测试、语法、类型和生产构建全部通过 | `test_results.md` | 合格 |

所有初衷级条目均合格。本清单在发现旧页面状态干扰后从起点使用全新标签页重新执行，最终证据来自重跑结果。
