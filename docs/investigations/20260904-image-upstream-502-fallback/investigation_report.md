# 角色生图上游 502 回退调查

## 用户现象

工程 `20260904043536-成都粉子-5b71f8` 的小燕子角色卡片生成形象时，页面显示非 JSON HTTP 502，并提示服务可能正在重启。

## 行为链路

1. 浏览器调用 `POST /api/projects/:projectId/roles/:roleId/portrait`。
2. Product Studio 选择主图像模型 `gemini-3.1-flash-image`。
3. 兼容供应商网关返回 HTML HTTP 502。
4. 旧版 `isImageCooldownError` 未把 502 识别为临时上游故障，互补模型 `gpt-image-2` 没有执行。
5. 公网反向代理替换或截断 502 错误体，前端只能显示通用非 JSON 提示。

## 根因

图像双模型回退机制的临时错误分类只覆盖 429、503、资源耗尽、限流和配额信号，遗漏供应商网关 500、502、504、超时和连接中断。最终错误沿用供应商 5xx 状态，使公网代理有机会把 Product Studio 的 JSON 诊断替换成 HTML。

## 修复

- 临时上游错误扩展到 HTTP 408、425、429、500、502、503、504，以及超时、连接重置、连接拒绝、DNS 临时失败和常见网络错误文本。
- 兼容服务错误保留供应商 `statusCode`，并为供应商 5xx 设置浏览器 `responseStatusCode=424`。
- 回退判断继续读取供应商状态，最终路由响应优先使用浏览器响应状态。
- 前端非 JSON 提示改为检查请求链路、反向代理和上游生成服务，移除未经证实的服务重启判断。
- 需求 129、137、README、架构文档和 CHANGELOG 同步更新。

## 证据边界

自动测试已经证明 HTML 502 会从 Gemini 切换到 GPT Image 并返回 HTTP 200 图像。当前生产供应商是否自然返回 502 具有时效性，真实浏览器验收记录当前实际结果；若供应商已经恢复，502 分支以受控测试为验收证据。
