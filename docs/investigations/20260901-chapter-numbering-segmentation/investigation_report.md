# 章节编号与边界规范化调查报告

## 用户目标

1. 分句导演中的章节显示为简短编号。
2. 章节不得使用完整台词。
3. 章节必须来自真实的原文章节边界，禁止一句一章。

## 根因

`text_director.py` 允许模型为每条分句自由生成 `section` 字符串。`product-studio/src/App.tsx` 直接显示该字段，完整台词因此进入章节单元格。交付阶段又按该文本分组章节音频，使 UI 问题继续扩散到交付结构。

## 规范结果

1. 只识别原文中的正式章节标题，包括“第 N 章”同类中文标题和 `Chapter N`。
2. 每条分句按 `source_text` 在原文中的顺序位置归属章节。
3. 无正式标题的文章整篇归入“第 1 章”。
4. UI、工程保存、AI 新分析和章节音频分组统一使用“第 N 章”。
5. 场景、自然段和分句保持独立层级。

## 生产数据迁移结果
