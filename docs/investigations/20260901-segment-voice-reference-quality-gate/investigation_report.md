# 分句音色参考与候选门禁调查报告

## 用户问题

第 165 条分句多次生成后音色明显偏离角色样本，页面选择的态度、情绪、句内节奏、情绪演绎和权重缺少可理解的生效证据，三个异常候选仍显示“质量通过 20.00”。

## 已验证事实

1. 角色 `role_001` 当前音色是 `voice-4a4c22c6757bbf00`，生产调用把对应 WAV 作为 `spk_audio_prompt` 传给 IndexTTS。
2. 第 165 条选择“低声”，角色级节奏是“紧凑清晰”。旧实现把两条互相竞争的节奏提示同时放入 `emo_text`。
3. 旧实现把 `duration_factor` 固定为 `1.0`，现有 `PACE_FACTORS` 没有进入生产调用。
4. 旧候选验收只检查 WAV 时长、RMS、峰值、削波、静音和可选重音代理。第 165 条没有重音文字，三个基础 WAV 合格候选都得到 `20.00`。
5. 最近两次六个候选与角色样本的 CAMPPlus 余弦相似度为 `0.633381`、`0.833116`、`0.727141`、`0.662972`、`0.650003`、`0.757017`。最新自动采用项为 `0.662972`。

## 根因

旧“质量通过”表示 WAV 文件基础可用，没有验证角色音色相似度，也没有验证完整导演效果。高级生成把基础评分最高的第一项立即写入现行片断，使音色偏离候选可以在人工试听前生效。分句节奏和角色节奏缺少明确优先级，结构化时长控制也没有接入。

## 修复契约

1. 分句节奏为“自然”时允许补充角色节奏。选择其他分句节奏时只发送分句节奏，避免冲突。
2. 使用现有 `PACE_FACTORS` 传递结构化 `duration_factor`。
3. 复用 IndexTTS 已加载的 CAMPPlus，计算角色样本与候选 WAV 的余弦相似度。当前门禁为 `0.72`，算法和阈值进入缓存签名及候选审计数据。
4. 综合通过需要基础音频通过、音色门禁通过，以及存在重音目标时重音代理通过。
5. 导演效果标记为 `human_listening_required`，页面不再把它表述为自动验收通过。
6. 已有片断执行高级重生成时继续保留。三个候选都保持未采用状态，系统门禁用于提示和排序，所有候选允许使用者按实际试听结果采用。待复核候选的采用记录为人工覆盖。

## 限制

`0.72` 来自本次同角色真实候选分布和当前异常样本的保守分界。后续可以用更多同角色正常片断和不同角色负样本扩充校准集。导演项仍属于 IndexTTS 情绪文本和时长控制范围，最终听感需要人工试听。
