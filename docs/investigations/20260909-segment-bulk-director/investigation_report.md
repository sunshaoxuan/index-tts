# 分句导演多字段批量修改调查与交付报告

## 问题

分句导演的批量工具只把句内节奏写入 `SegmentRow[10]`。角色、语言、态度、情绪、停顿、情绪演绎、情绪权重和生成方式虽然均可逐行编辑，却没有批量入口。

## 结论

批量工具已改为“字段、值、应用范围”结构，支持角色、语言、态度、基础情绪、句内节奏、句后停顿、情绪演绎、情绪权重和生成方式。应用范围支持跨分页保留的已选分句和全部分句。

角色更新同步稳定角色 ID 与名称。具体情绪演绎预设同步建议权重，`auto` 和 `custom` 保留现有权重。停顿与情绪权重分别校验 0 至 3000 和 0 至 1。未选行、未修改字段和无变化批次保持原状态。

依赖单句语义的合成文本、情绪细化描述和重音目标继续逐行设置。

## 运行验收

正式镜像为 `indextts25-product-studio:1.1.93-0a17911`，镜像 revision 为 `0a179117ef64dc89030c116c2bc21cad5c1a2f7f`。容器运行状态与健康状态均正常，重启次数为 0，验收期间活动任务为空。

正式页面显示全部九个批量字段。真实工程中选中第 1 条分句，把停顿从 300 临时批量设置为 350；页面读取结果为前三条 `350, 300, 300`。随后把第 1 条恢复为 300、保存工程并清除选择。桌面与 390 x 844 窄屏截图检查均未发现控件重叠、截断或横向溢出。浏览器 Console 的 error 和 warn 记录均为 0。
