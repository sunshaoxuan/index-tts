# 分句级情绪演绎实现与验收报告

## 结论

分句导演现已为每条分句提供演绎预设、自定义细化描述和 0 至 1 情绪权重。选择预设时采用对应建议权重，渲染阶段把预设英文提示、细化描述、角色节奏、句内节奏、态度和基础情绪组合为 IndexTTS 2 的 `emo_text`，并把权重传入 `emo_alpha`。

旧 12 列工程在读取和保存时补入 `auto` 与空描述。预设、细化描述和权重进入缓存签名与导演清单，编辑其中任一项只使对应分句片断失效。无匹配片断时逐句按钮显示“生成本分句”，存在匹配片断时显示“重新生成本分句”。

## 行为链路

1. `/api/presets` 返回演绎 ID、中文标签、详细英文提示和建议权重。
2. React 分句行保存预设 ID 到第 13 列，保存细化描述到第 14 列，并继续使用原第 10 列作为情绪权重。
3. 工程 PUT 校验预设、描述长度、自定义描述必填及权重范围。
4. `tables_to_script` 读取 14 列并构造规范化分句对象。
5. `segment_emotion_text` 按显式演绎、角色节奏、句内节奏、态度和基础情绪的顺序组合提示。
6. `render_directed_audio` 把组合提示传入 `emo_text`，把权重传入 `emo_alpha`，并写入缓存签名和导演清单。
