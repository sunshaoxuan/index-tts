# 分句导演紧凑行重新设计报告

## 目标

把占用过高的分句导演记录收敛为两条信息带。第一条只显示基本分句信息，第二条从紧凑播放器和生成操作开始排列所有影响音色的控件。

## 实现

1. 第一条信息带只保留序号、章节、原文和合成文本。
2. 角色、语言、态度、情绪、节奏、停顿、演绎、权重、重音和生成方式全部进入第二条音色编辑带。
3. 匹配片断使用 150px 宽自定义播放器，提供播放、暂停、当前时间、总时长和重新加载入口。
4. 无匹配片断时首格只显示“生成”按钮，不渲染空播放器或缺失说明。
5. 普通分句不为三版候选预留高度；候选实际存在时追加独立三列、两列或一列区域。
6. 桌面布局使用具名 CSS Grid，窄屏保持两列换行且不产生横向溢出。

## 结果

1920px 宽真实页面中，首条普通记录总高约 280px，基本信息带约 63px，音色编辑带约 174px，播放器首格宽 150px、高 63px。原截图中的单条记录占据大部分可视区，修改后一屏可完整显示两条普通记录及第三条基本信息。

## 限制

高级三版候选按需求保留完整验收卡片，因此实际存在三版候选的记录仍会追加较高候选区。该高度只出现在有候选数据的分句。
