# 全页签视觉分区验收矩阵

## 原始初衷

所有存在轻微背景的页面都要形成可辨识的信息区边界，降低连续大面积内容造成的阅读疲劳。六个页签和共享控件需要使用一致的信息层级，并在桌面、窄屏和移动端保持清晰、无横向页面溢出。

## 分区层级

| 层级 | 可检查对象 | 视觉要求 |
| --- | --- | --- |
| 页签工作区 | 当前页签内容外框 | 与页面背景形成稳定边界，标题区和内容区可立即区分 |
| 主分区 | 原文、场景集合、角色集合、导演表、纠音表、交付区 | 具有统一内边距、暖色半透明填充和清晰边框 |
| 嵌套分区 | 场景卡、角色卡、提示区、播放器、字幕、下载区 | 与主分区形成可见明度差和间距 |
| 行级项目 | 表格行、字幕行、候选声音、字段组 | 通过分隔线、局部底色或留白维持连续阅读定位 |

## 分句专项

相邻行计算底色分别为 `rgba(80, 45, 24, 0.5)` 与 `rgba(16, 9, 4, 0.46)`。桌面、窄屏、移动端表体宽度分别为 1310=1310、850=850、296=296。分页 10、20、50、100 条均按选择数量渲染。

## 验收重启规则

任一条目不合格时立即返工。返工后从六个页签桌面检查起点重新执行完整验收。
