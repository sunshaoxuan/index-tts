# 全页签视觉分区调查报告

调查确认三个根因：工作区表面层级过近；分页使用固定 `pageSize: 20` 导致选择被受控值覆盖；十三列宽表强制横向滚动。移动端还发现页签导航只能横向滚动，后续页签点击可被浮动操作面板影响。

实现统一四级表面和边界；分页改为受控 `current` 与 `pageSize`；分句表改为单个复合列的上下两层记录；相邻记录使用强交替底色和实体分隔；移动端页签改为两列多行完整展示。

最终从六页签起点重跑三种尺寸。所有页签可达，页面无横向溢出，分句表无横向滚动，Console 为空。

后续可读性复核确认分句字段标签仅有 9px、字段值与原文仅有 12px、片断说明仅有 10px。修正后标签为 12px 且文字对比度提高，主要字段值与原文为 14px，片断说明为 12px。三种尺寸的计算样式、溢出和截图检查均通过。
