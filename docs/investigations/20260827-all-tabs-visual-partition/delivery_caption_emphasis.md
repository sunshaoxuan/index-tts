# 完整播放当前字幕突出效果

## 需求

完整播放区域的当前字幕需要提供更强的视觉焦点。角色名和正文应保持更大的稳定字号，播放位置变化或拖动进度条定位时，新的当前字幕应执行一次短促的放大回落动画。

## 实现约束

| 项目 | 要求 |
|---|---|
| 当前角色名 | 从普通状态 10px 提高到 12px |
| 当前正文 | 从普通状态 13px 提高到 16px |
| 焦点动画 | 400ms，从 0.985 倍经过 1.018 倍回到 1 倍 |
| 稳定布局 | 动画结束后保持 1 倍缩放，字号继续维持高亮尺寸 |
| 动态效果偏好 | `prefers-reduced-motion: reduce` 时关闭动画，保留静态字号和颜色高亮 |
| 手机排版 | 800px 以下改为角色名在上、正文在下的单列结构，正文使用完整可用宽度 |
| 边界 | 字幕容器和页面均不得产生横向滚动 |

## 验收范围

1. 计算样式确认当前角色名为 12px、当前正文为 16px，动画名称和时长符合设计。
2. 播放推进后，当前字幕索引发生变化，新的当前项具有焦点动画。
3. 拖动音频进度后，当前字幕索引发生变化，新的当前项具有焦点动画。
4. 1440×1000、980×900、390×844 三种视口检查字幕区和页面横向边界。
5. 三种视口截图检查当前字幕可读性和信息层级。
6. 浏览器控制台检查错误和警告。
7. 单元测试和生产构建通过。

## 证据状态

首次运行验收发现 390px 视口仍沿用双列结构，正文宽度只有 37px，一条当前字幕高度达到 597px。该项判定不合格，已按最终验收规则增加手机单列排版，并从完整测试和浏览器验收起点重新执行。
