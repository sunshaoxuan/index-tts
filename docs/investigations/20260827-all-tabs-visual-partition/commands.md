# 命令记录

1. 检查 Git 分支、状态、最近提交和 7864 监听进程。
2. 检索 `product-studio/src/App.tsx`、`product-studio/src/styles.css` 和现有测试中的页面结构与样式契约。
3. 使用内置浏览器访问 `http://127.0.0.1:7864/`，建立六个页签的桌面基线。
4. 执行 `pnpm test`、`pnpm run build` 和 `git diff --check`。
5. 每次构建后重启 7864 服务，避免静态资源哈希与运行服务不一致。
6. 在 1440×1000、980×900、390×844 下逐页点击六个页签，记录页面宽度、表体宽度、分页行数、交替底色、Console 和截图。
