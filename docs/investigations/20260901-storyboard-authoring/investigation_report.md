# 视频分镜多镜头编排调查与实现报告

## 需求结论

视频分镜采用场景和镜头两层结构。场景描述主题、地点、方位、观察方向和叙事焦点，场景内部继续拆成多个短镜头。一个镜头对应一张关键帧。默认目标时长为约 10 秒，20 分钟音频在内容边界允许时形成约 120 个镜头。

分镜工作台提供以下直接入口：

1. AI 重新生成全部分镜。
2. 手工创建分镜镜头。
3. 从中间分句拆分镜头。
4. 勾选同一场景内的相邻镜头并合并。
5. 生成或重新生成单张关键帧。
6. 选择统一风格并生成或重新生成全部镜头关键帧。

## 数据与时间边界

AI 全量重建只更新场景、分句的场景引用、镜头清单和相关描述。稳定角色、当前分句拆分与合并、人工朗读文字、音频片断及候选、纠音规则和导演记忆继续保留。

已有完整音频时，后台读取最近交付清单中的真实 WAV 时长和句后停顿，建立累计时间线，再按连续分句和目标时长形成镜头。没有完整音频时，后台按文字长度估算边界，镜头不保存音频起止秒数，页面也不显示音频时间。

## 实现路径

| 行为 | 入口与实现 | 验证状态 |
|---|---|---|
| AI 全量重建 | `POST /api/projects/:id/storyboard/regenerate`，`product_analysis_worker.py`，`storyboard_regeneration.py` | 自动化测试通过 |
| 单镜头关键帧 | `POST /api/projects/:id/scenes/:sceneId/shots/:shotId/keyframe` | API 测试通过 |
| 全量镜头关键帧 | `POST /api/projects/:id/storyboard/keyframes`，最多 500 个镜头 | API 测试通过 |
| 手工创建 | `createManualStoryboardShot` | 单元测试与浏览器弹窗检查通过 |
| 拆分 | `splitStoryboardShot` | 单元测试与浏览器交互通过 |
| 合并 | `mergeStoryboardShots` | 单元测试与同镜像隔离浏览器复验通过 |
| 镜头选择 | `toggleStoryboardShotSelection` | 浏览器发现缺陷后返工，单元测试通过 |

## 浏览器返工记录

首次生产交互中，镜头拆分成功，镜头总数从 5 变为 6。同场景勾选第二个镜头时，第一个选择被清除，合并按钮无法启用。原因是选择状态更新会过滤当前场景的全部已有选择。

返工后，选择逻辑保留当前场景内的已有镜头选择，勾选其他场景时清除上一场景选择。新增单元测试覆盖同场景多选、取消选择和跨场景切换。

## 浏览器验收结果

生产 7864 在重新部署后继续运行一个用户发起的完整音频渲染任务。该任务保持运行。浏览器返工复验使用同一镜像 `indextts25-product-studio:1.1.59-storyboard-working` 启动 7865 隔离实例，工程数据位于任务专属目录。

隔离实例中先把一个镜头拆成两个 4.9 秒镜头，再同时勾选两个相邻镜头并成功合并。合并后镜头范围恢复为第 1 至 2 句和 0.000 至 9.800 秒，旧关键帧清除，页面显示合并成功回执。

桌面视口为 1280×720，移动视口为 390×844。两种视口的页面横向溢出均为 false，Console 日志均为空。桌面分镜工作台、移动全页和手工创建弹窗截图保存在 `artifacts/storyboard-authoring-20260901`。

SSD 模型卷切换并重新创建生产容器后，当前 7864 实例再次完成只读页面检查。视频分镜工作区显示目标镜头时长、AI 重新生成全部分镜、手工创建分镜镜头和全量关键帧入口，4 个场景均呈现场景内镜头清单。当前工程尚未执行新分镜重建，因此镜头数量为 0；空状态明确引导使用者从 AI 全量重建或手工创建进入。1280×720 页面无横向溢出，Console error 与 warning 为 0，当前生产截图为 `storyboard-production-7864-current.png`。
