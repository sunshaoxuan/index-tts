# 分句重音、自主验收与移动端稳定性调查

## 目标

调查 IndexTTS 官方最新版本，并在现有分句情绪控制基础上设计可落地的重音概率增强、多候选自主验收、高级三版选择和移动端稳定性改进。

## 已验证结论

1. 2026-08-31 官方仓库仍将 IndexTTS 2.5 标为最新版本，发布时间为 2026-08-10。
2. IndexTTS 2.5 原生支持整句情绪文本、情绪权重和语速时长因子。
3. 当前引擎没有词级重音参数。重音目标需要进入情绪提示，并由多次采样与声学验收提高命中概率。
4. 当前产品的分句情绪字段已经进入缓存签名和渲染清单，可在同一链路加入重音目标与候选结果。

## 已实现范围

1. 数据契约保存重音文字、出现序号和重音强度。
2. 前端校验重音文字确实存在于当前分句。
3. 后端构造明确的英文重音提示，生成候选并进行声学评分。
4. 高级生成选项固定提供三版通过基本校验的结果供选择；设置重音后持续抽取到三个代理达标候选或用完九次预算，并披露未达标项。
5. 移动端稳定滚动、稳定弹窗占位、阻止横向溢出和动态布局跳动。

## 真实模型返工结论

首次真实高级生成在三次基础质量合格后提前结束，三个候选的重音代理均未达标，同时旧单版缓存与新三版缓存以相同序号重复返回。返工后，设置重音目标时会继续抽取到三个代理达标候选或用完九次预算；页面数据按分句序号只保留最新缓存。基础质量合格但重音代理未达标的候选仍可在预算耗尽时返回，界面明确显示“概率增强”，不会宣称为精确词级控制。
